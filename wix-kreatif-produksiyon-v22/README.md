### Installation
1. Open the existing Kreatif Prodüksiyon page in Wix Studio.
2. Select the existing Custom Element and choose **Choose Source → Server URL**.
3. Replace the old URL with the exact version-pinned URL above.
4. Change Tag Name to `n1-kreatif-produksiyon-v22`; remove the old element if it is separately embedded to avoid duplicate header/footer.
5. Review 390px, 820px and desktop. Test sticky image, video, timeline, mobile controls and footer height.
6. Save, then click **Publish**.
