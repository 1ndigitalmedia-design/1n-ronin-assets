## Wix Studio'da yayına alma
1. `/e-ticaret-yonetimi` sayfasını Studio editöründe açın veya yoksa bu slug ile oluşturun.
2. Sayfanın ana içerik alanında mevcut eski Custom Element varsa onun kaynağını güncelleyin; yeni öğe eklemeniz gerekiyorsa sadece bir tane kullanın.
3. Custom Element → Choose Source → Server URL: yukarıdaki URL.
4. Tag Name: `n1-e-ticaret-yonetimi-v1`.
5. Header/Footer/WhatsApp mevcut Custom Element tarafından yüklendiği için ikinci kopya oluşturmayın. Bileşen genişliği tam, yükseklik doğal/içeriğe göre olmalı.
6. Test Site'ta en az 390px mobil, 820px tablet, 1440px masaüstü ve Hero/Omurga videoları ile CTA'ları test edin.
7. Doğruladıktan sonra Wix Studio **Publish**.

**Önemli:** GitHub kaydı Wix Studio editörünü kendiliğinden güncellemez. Canlı yayın ancak Wix'te kaynak URL'si ve tag name kaydedildikten sonra yapılmalıdır.
